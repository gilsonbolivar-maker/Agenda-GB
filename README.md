# Agenda GB

PWA de painel + agenda. Sem IA.

Os dados ficam no próprio aparelho (localStorage).
WhatsApp, Hotmail, Drive e OneDrive abrem o site oficial.

Repositório: https://github.com/gilsonbolivar-maker/Agenda-GB

Para publicar: Settings → Pages → Branch `main` → pasta `/ (root)` → Save.
Site: https://gilsonbolivar-maker.github.io/Agenda-GB/

## Usar

1. Abra o site publicado.
2. iPhone: Compartilhar → Adicionar à Tela de Início.
3. Android Chrome: menu → Instalar aplicativo.
4. Ajustes (engrenagem): nome, turno de hoje e links.

## Exportar

Em Ajustes → Exportar. Gera um JSON de backup.
